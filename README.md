# FocusGrid Life OS

Application web monopage autonome (un seul fichier HTML) : suivi d'habitudes avec heatmap 16 semaines, matrice d'Eisenhower, check-in quotidien, temps d'écran, objectifs à 90 jours et tableau de bord de synthèse.

## Utilisation

Ouvrir `focusgrid-life-os.html` dans un navigateur. Aucune installation ni build. Les données sont sauvegardées localement dans le navigateur (localStorage).
